# Document Review & Data Quality Analysis

A portfolio project demonstrating document review, structured data extraction, SQL querying, Excel analysis, and data-quality checks using **fictional customer-document records**.

## Skills Demonstrated
- Reviewing semi-structured document information
- Converting document fields into structured tabular data
- SQL filtering, grouping, duplicate detection, and `CASE` logic
- Excel formulas, conditional formatting, summary metrics, filtering, and charts
- Data-quality checks for missing, expired, duplicate, pending, and failed records

## Project Structure
```text
sample_documents/  Fictional text-based document samples
data/              Structured document-review dataset
sql/               SQL quality-control queries
excel/             Excel review workbook and dashboard
reports/           Summary of findings
```

## Review Checks
- Expired documents
- Missing fields
- Duplicate document numbers
- Verification status
- Document-type distribution
- Simple review-priority classification

## Important
All customer IDs, document numbers, dates, countries, and review statuses are synthetic and created for educational and portfolio purposes only.
